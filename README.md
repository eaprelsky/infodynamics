# Инфодинамика

Формальная теория информационных процессов: как информация трансформируется, встречает инерцию, каскадно усиливается и синхронизирует модели мира на масштабах от нейрона до цивилизации.

**Статус:** ранняя стадия, поиск формализма.

---

## Структура

```
observations/       Что мы наблюдаем (феномены, очищенные от интерпретаций)
  MANIFESTO.md      Четыре наблюдения, свойства информации, что не работает в v1

theory/             Поиск математики
  TERRITORY_MAP.md  Карта явлений через пять масштабов, сквозные паттерны
  RESEARCH_MAP.md   Математические кандидаты для формализации
  TRANSFORMATION_ACROSS_SCALES.md   Трансформация через масштабы (глубокий анализ)

experiments/        Дизайн экспериментов (будет наполняться)
```

## Контекст

Инфодинамика v1 (2025) пыталась описать информационные процессы через аналогию с электрическими цепями. Аналогия педагогически полезна, но как формализм ломается: информация не сохраняется, не подчиняется законам Кирхгофа, контекстозависима, каталитична. V2 начинает с наблюдений и ищет математику, которая органично вырастает из природы информации.

Полная история v1 доступна в git-истории репозитория.

## Направление

Центральная гипотеза: информация это не "вещество", которое "течёт", а событие, которое изменяет модель мира агента. Формальный аппарат должен описывать пространство моделей мира и динамику их обновления.

Кандидаты первой очереди: Information Bottleneck (Tishby), байесовский вывод с precision, Active Inference (Friston).
